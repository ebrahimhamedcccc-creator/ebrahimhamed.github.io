---

## سياسة الخصوصية

**آخر تحديث:** أكتوبر 2026

### البيانات التي نجمعها

لا يجمع هذا التطبيق أي بيانات شخصية من المستخدمين. كل شيء يعمل محليًا على جهازك.

### البيانات التي نشاركها

لا نشارك أي بيانات مع أي طرف ثالث. الفيديوهات والصور والنصوص محفوظة محليًا على جهاز المستخدم.

### استخدام YouTube API

يستخدم هذا التطبيق YouTube Data API v3 حصريًا لرفع الفيديوهات التي ينشئها المستخدم إلى قناته الخاصة على YouTube. لا نستخدم الـ API لأي غرض آخر، ولا نجمع أي بيانات من YouTube.

### أمان البيانات

- كل البيانات محفوظة على جهاز المستخدم.
- لا يوجد خادم خارجي يحتفظ بأي بيانات.
- المفاتيح والرموز محفوظة في ملفات محلية على الجهاز.
